## Activation Checklist (make the automation real)

This platform is deliberately self-contained. Complete these steps to unlock full marketing automation and payments:

1. **Stripe Payment Links** (Shop / Academy / Membership)
   - Create Payment Links or Products in your Stripe Dashboard.
   - Replace the placeholder “Order / Enrol / Join” buttons with your live Stripe Payment Link URLs.
   - Optional: add `?client_reference_id=` or UTM for tracking.

2. **Calendar Booking**
   - Create a Calendly or Cal.com event type.
   - Paste the embed code or link into `/book` (clear slot already prepared in the design).

3. **Email & Marketing Sequences**
   - Use Resend, ConvertKit, Mailchimp, or Gmail + Automations.
   - Ready-to-paste nurture sequences are outlined on the Command Center and can be expanded.
   - Forms currently use mailto for zero-config; swap to Formspree / Tally / webhook for automated delivery into sequences.

4. **Visual Content First Batch**
   - Export 50–100 strongest images from Google Photos dachshund/farm albums.
   - Generate metadata and upload to Adobe Stock + Shutterstock + Pond5.

5. **Referral & Adaptive Tracking**
   - The Referral page + UTM-ready links support viral growth.
   - Command Center checklist persists in the browser (self-directed progress).

6. **Custom Domain (optional)**
   - Point your domain to the Vercel project `therapy-sausages-empire`.

Once the above are live, the system becomes fully automated, self-directed and adaptive while remaining simple and ownership-complete.
